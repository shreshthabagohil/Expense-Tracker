# Advanced Expense Tracker (Java)

A multi-user, console-based expense tracking application built using Java and MVC architecture.

## Features
- Multi-user support (separate data per user)
- Persistent storage using CSV files
- Add and view expenses
- Monthly expense summary
- Category-wise analytics
- Clean MVC architecture
- Easily extendable to GUI or Web

## Tech Stack
- Java
- Maven
- OOP
- File I/O (CSV)
- MVC Design Pattern

## How to Run
1. Clone the repository
2. Open the project in VS Code or IntelliJ
3. Run `App.java`
4. Enter a username
5. Start tracking expenses
